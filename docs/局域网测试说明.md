# 局域网测试

当前主机的局域网地址为 `192.168.0.97`，网站使用 TCP 8000 端口。

1. 在作为服务器的这台电脑上启动项目：在项目目录运行 `powershell -ExecutionPolicy Bypass -File scripts/start.ps1`。运行期间保持电脑开机、联网，不要关闭服务进程或让电脑进入睡眠。
2. 其他电脑连接同一路由器或公司局域网，在 Chrome/Edge 地址栏打开 `http://192.168.0.97:8000`。其他电脑不需要安装 Python、Node.js、数据库或 OCR。
3. 超级管理员在“管理与公共资料 → 账号与权限”中为测试人员分别建立账号。每人使用自己的账号登录，便于区分操作记录。
4. 先用测试台账和测试图片验证上传、识别、核对、导出。手机连接相同 Wi-Fi 后也可使用这个地址。

Windows 防火墙规则 `Yuanfuliao-LAN-8000` 仅允许本地子网访问网站端口。需要重新设置时，以管理员身份运行 `scripts/enable-lan.ps1`。不需要开放数据库端口，也不需要设置路由器外网端口映射。

如果无法访问，依次检查本机能否打开 `http://127.0.0.1:8000`、主机是否开机且服务正在运行、客户端是否在访客网络或启用了网络隔离。通过 `ipconfig` 查看主机 IPv4 地址；如果 DHCP 改变了地址，请使用新地址。可在路由器为主机保留固定 DHCP 地址。

局域网 HTTP 可以上传、识别和分别选择个人 Word/Excel 模板文件，不要求固定文件名。选择后副本按账号保存在当前浏览器，修改本地文件后需要重新选择文件。公司服务器正式部署使用 HTTPS。

此地址用于局域网测试。HTTP 不加密传输，超级管理员查看密码时也会受此限制；请在可信局域网使用测试账号，正式部署通过 HTTPS 访问。

## 本机自动运行

当前测试机已注册 Windows 计划任务 `Yuanfuliao-Web`，由当前 Windows 用户登录后自动启动，隐藏运行本地数据库与网站；不依赖临时终端窗口。异常退出时每隔一分钟重试，最多三次。数据库异常恢复的启动等待已延长至60秒。

其他 Windows 测试机需要相同配置时，在项目目录运行 `powershell -ExecutionPolicy Bypass -File scripts/install-startup-task.ps1`。可在任务计划程序中查看运行状态、手动启动或停止；已运行时不要再重复执行 `start.ps1` 占用8000端口。关机、睡眠或尚未登录 Windows 时网站不可访问，正式公司服务器另行配置系统服务。
