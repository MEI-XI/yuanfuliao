# 本地运行与模板维护

## 识别进度与人工复核反馈

识别按钮旁显示提交、排队数量、识别中和完成状态。处理期间不能重复点击；同一用户对同组图片重复提交会复用仍在处理的任务。状态查询中断时点击“重试获取状态”，只恢复中断组，不重跑已经完成的组。识别中仍可人工填写和保存。

保存并标记“已核对”后，记录可作为后续识别参考。这是复用人工复核资料，不会自动训练或修改 OCR 模型参数。新照片识别出的物料名称（含型号）、单位名称、规格三项均完整且与历史原识别内容或核对内容匹配时，参考已核对的名称、规格、单位、地址、电话和保质期，自动填入空白字段。已有内容、人工清空或人工选择的来源不覆盖。

参考区显示公司台账、记录编号、版本及核对日期。日期、接收数量、检验结果和结论每次单独填写；当前或历史图片的物料身份有冲突、多条参考记录对同一资料有不同值时，不自动采用有歧义的资料。地址/电话与供应商或生产商来源成对带入。记录修改为待核对、或作废后，不再作为新的自动填入参考。

## 当前电脑

项目位于 `D:\DOME\yuanfuliao`，双击 `启动本地测试.cmd`，保持启动窗口开启，用浏览器访问 `http://127.0.0.1:8000`。启动时自动检查数据库并执行版本迁移。

首次访问建立超级管理员账号；已有系统的 admin 账号在本次升级时成为超级管理员。之后管理员在“管理与公共资料”维护账号、角色、公司台账、物料、检验标准方案和单位资料。没有公开注册入口。系统不预置业务账号或通用密码。

当前电脑使用项目专属 PostgreSQL，监听 `127.0.0.1:55433`，数据目录 `data/postgres-local`。连接信息在本地 `.env` 中；不要将该文件提交代码仓库。关闭网页服务不会删除数据库。停止网页服务按 Ctrl+C；若需要停止项目数据库，可运行 `tmp/pg-runtime/pgsql/bin/pg_ctl.exe -D data/postgres-local stop`。

同事在其他电脑上测试时，只需浏览器打开局域网网站，不需要安装依赖。将来更换服务器时，服务器按 README 安装依赖、提供 PostgreSQL，并从 `.env.example` 建立 `.env`。本机临时下载的便携数据库程序在 `tmp/pg-runtime`，不在 Git 仓库内，不是通用安装器。

## 手机和电脑

本地阶段：手机与电脑连接同一个局域网，在手机浏览器输入 `http://电脑局域网IP:8000`。电脑可用 `ipconfig` 查看当前网络 IPv4 地址。Windows 防火墙如拦截，允许 Python 服务的专用网络访问。当前阶段不配置公网映射。

手机支持相册选图和拍照上传，电脑支持选择文件和拖放。批量模式默认一图一组。图片左侧的窄栏按“记录 → 图片缩略图”分层纵向显示，点击子图片直接预览。拖动记录手柄调整分组顺序，电脑和手机均支持，也可聚焦手柄使用上下方向键；顺序改变不会移动图片所属记录或丢失当前填写内容。识别到相同物料会给出合并提示，人员决定是否合并、移动或拆分。已保存记录通过修改或作废重建处理。

全部有效记录均可查看和按规则导出；普通用户只修改、核对自己的记录，管理员可修改全部记录并作废。默认选择已核对记录导出，待核对需确认，作废不能导出。

## 识别与核对

本地 RapidOCR 先运行，识别后台排队，人员可以继续手填和保存。默认启用云端辅助，但没有密钥或服务失败时仍能使用本地结果。管理员可配置智谱密钥，型号固定为 `glm-4.1v-thinking-flash`，不切换收费型号。云端服务的可用性与免费政策由提供方决定，无法保证永久免费。

管理员在“管理与公共资料 → 云端与模板”粘贴智谱官方 API Keys 页面的完整密钥，先点“保存密钥”，再点“测试连接”。测试使用服务器保存的密钥，验证认证及模型文字请求；包装识别效果仍需上传照片核对。HTTP 401 表示认证失败，需重新复制完整有效密钥；403 检查账号权限，429 检查限额并稍后重试。云端错误也显示在识别按钮旁，本地结果保留。密钥不会回显或提交 Git。

识别建议不会覆盖人工修改。保存后仍能打开原图和识别原文。生产日期显示与导出为 `2026.01.14`；Word 原有“生产日期批号”使用该日期，独立“批号”保持空白。接收数量、检验结果和结论每次由人员填写，可留空。

图片不清楚、地址电话很小、产品名称被折痕遮挡时，查看原始文字、补拍特写或手动修正。不要把历史台账中的日期、收货数量或检验结果作为本次识别事实。

## 回收站

作废记录从公司台账和“全部记录”中移除，单独放在顶部“回收站”。所有已登录人员可查看并按公司或物料搜索，管理员可还原。还原保留原字段、检验内容、图片与历史，回到待核对状态，需重新核对后使用。

超过作废时间 30 天的记录及其修改历史自动永久删除，不能再还原。服务启动时和运行中每小时清理一次，进入回收站时也清理到期记录；停机期间不运行，重新启动后补清理。旧作废记录以原作废操作更新时间起算。共享的照片和识别任务不会因某条记录到期而删除，避免影响其他记录。

## 批量保存

多种物料批量录入后，勾选需要保存的分组，可用底部“全选分组”“全部清空”调整选择。底部显示“保存所选 N 条记录”，与“同时标记为已核对”勾选项放在同一栏，替换单条保存按钮。核对选项默认不勾选；所选组按当前分组顺序保存，未选组保留在录入界面。检验/未检验状态仍分别取各组设置。没有勾选时可按原方式保存当前记录。

任一组校验失败，整批均不保存；草稿保留供修正。识别正在处理时等待完成后再批量保存，仍可按原方式逐条保存。若网络中断、尚未确认提交结果，临时锁定本批草稿，点击“重试批量保存”继续确认同一批次，避免重复创建。

## 检验方案与导出选择

新增记录默认“未检验”，检验项目和报告信息收起并锁定。选择“检验”后展开；切回“未检验”保留已填内容，再次开启可继续填写。“检验”表示启用本次检验，不等同于已核对或检验合格。更新前的已有记录保留原报告能力，显示为“检验”，人员可自行切换。

新记录的检验日期默认当天，使用上海时区，仅年月日，可修改或清空。重新打开已有记录不改写原日期。检验项目只填写项目、标准规定、检验结果和判定结论，不再提供单位字段；历史独立单位不再附加到报告项目名称。

台账另列“检验状态”。Excel 可导出未检验记录；Word 只允许检验记录。所选记录中包含未检验记录时，提示取消勾选后再导出，不会静默跳过。

检验标准方案的所属物料可留空。所属物料仅作提示，所有物料都能选择任意方案；已开启检验时，选择仅绑定一套方案的物料，空白项目可自动带入。人员也可以从“已维护检验项目”中选择单项加入，其他已填结果保留。更换物料保留已有项目；明确选择“不选择方案”后，保存不会再自动改成另一套方案。已保存记录保留当时的项目快照。选择整套检验方案时，“检验依据”默认带入方案名称，可手动修改或清空；已经手改的依据不会被后续方案选择覆盖。

台账中先勾选需要的记录，可“全选当前记录”或“清空选择”。仅导出当前筛选中选中的记录。Excel 按公司分表，标题使用各表第一条导出记录的到货年份；首条日期为空则不带年份。多条 Word 每条单独生成一份并打包 ZIP，文件名为“品名_检验日期.docx”，未填检验日期时使用录入日期（上海时间）。重名依次加 `(1)`、`(2)`，非法文件名字符替换为下划线，过长品名只截短文件名，报告正文保持原文。

## 个人模板与签名

所有用户从顶部“我的模板”分别选择 Excel、Word 模板文件，不要求同名，不选择文件夹。每一行显示当前来源（服务器默认或个人模板）、文件名及个人模板选择时间，支持独立更换、恢复默认和下载默认模板。采用纯网页方案，局域网 HTTP 也可使用。

个人模板副本保存在当前浏览器，按账号区分。用 Office/WPS 修改本地文件后，请重新选择该文件；清除网站数据或更换浏览器后也需重新选择。选择时会临时上传服务器转换及检查结构，导出时再次临时发送，不替换服务器默认模板。每个输入文件不超过 10 MiB。

支持 Word 的 doc、docx、docm、dot、dotx、dotm、rtf、odt、Office XML，以及 Excel 的 xls、xlsx、xlsm、xlsb、xlt、xltx、xltm、ods、csv、Office XML。扩展名与内容必须相符，文件不能加密。Excel 必须保留 A1“原辅料查验记录”标题、表头行及13列；仅格式转换不会自动把任意表格变为查验台账。输出固定为 .xlsx 和 .docx，多份 Word 打包为 ZIP。

旧格式需要服务器转换工具：Windows 可使用已安装的 Microsoft Word/Excel；Linux 公司服务器安装 LibreOffice，可通过 `LIBREOFFICE_PATH` 指定 soffice 可执行文件。docx/xlsx 直接使用，宏及模板格式转换成普通文档。转换失败会提示，保留之前的个人模板。

报告信息不填写检验员和批准姓名。点击“修改模板文件”进入“我的模板”，设置后可返回继续录入。用 Word/WPS 修改签名图片并重新选择文件；导出保留模板签名图片。Word 支持原系统带占位符模板，也支持提供的“原辅料检验报告单”七行四列表格，后者直接填入对应空格及检验项目，不重建签名段落。自行设计其他版式时需保留字段占位符和项目循环标记。

服务器默认模板位置由 `TEMPLATE_DIR` 指定，默认 `templates`，由服务器维护人员管理。2026-10-15 已将指定的“模板文件夹/检验报告.doc”用 Microsoft Word 转为 .docx，转换前后渲染均为一页且逐像素一致，两张签名图保留。实际办公文件和签名不上传 GitHub，部署时另行复制。

导出包含未检验记录时，Excel 正常导出，不因未检验状态弹窗；Word 弹窗说明需先取消勾选未检验记录。待核对记录仍需确认。Excel 所有单元格居中、不自动换行，按内容计算列宽与行高；显式换行保留，列宽受 Excel 最大值255限制。

## 管理资料新增与修改

保留原有大分类，每个小模块首先显示自己的列表。例如“物料与检验标准”下分别显示共享物料列表和检验标准方案列表，每个列表有自己的新增入口。单位、账号和台账采用同样方式。

点击“新增物料”等按钮，进入该小模块的空白新增界面，按钮显示“创建物料”等。点击某条记录的“修改”，进入标题含原名称的修改界面，按钮显示“保存修改”。完成后自动返回列表；点击“返回列表”或“取消返回”不保存，下一次新增仍为空白，不沿用编辑对象。云端密钥也区分首次配置与更新界面，保存后回到列表测试连接。

## 管理资料删除

管理员可删除共享物料、检验标准方案、单位资料、人员账号和公司台账，删除前按名称确认。删除物料会解除方案及记录的物料关联，记录中的字段、项目、标准快照和历史仍保留；删除方案和单位资料同样不清空已保存记录。

当前登录账号不能删除；已有记录、核对历史、照片或识别任务的账号不能删除，可改为停用。已有记录、照片或识别任务的台账不能删除，仅允许删除空台账。云端设置可通过“清除密钥”移除密钥。

## 公司服务器部署准备

提供 `Dockerfile`、`compose.yaml` 和 Nginx 配置示例。当前环境没有 Docker，容器构建、公司服务器网络与 HTTPS 尚未实机验收，不能视为已部署。

服务器准备 Python/Node 构建环境或 Docker Compose、域名与 TLS 证书。Compose 使用单个应用进程和 PostgreSQL；在服务器 `.env` 设置 `POSTGRES_PASSWORD`（建议使用随机字母数字密码以避免连接串转义问题）。将本地模板单独复制到服务器 `templates`。服务默认只绑定回环地址，经 Nginx 提供 HTTPS；HTTPS 上设置 `COOKIE_SECURE=true`。

本版识别任务在数据库记录状态、单进程后台执行；重启中的任务会标记失败，用户可重试。不要直接增加 Uvicorn worker 数量；需要扩容时先改为独立队列执行器。

迁移包含数据库、`data` 中的上传图片、`templates` 以及服务端配置。数据库用 `pg_dump -Fc` 备份，以 `pg_restore` 恢复到新的数据库并验证；不要复制正在运行的 PostgreSQL 数据目录作为备份。模型可重新下载，已下载后断网也可运行本地识别。正式上线前进行恢复演练、HTTPS、手机外网访问及账号权限验收。

## 超级管理员与操作日志

超级管理员可修改账号名称、重置所有账号密码、分配普通管理员权限，并在“操作日志”中查看所有人员的新操作。超级管理员账号不可删除、停用或降级；普通管理员不能修改超级管理员或分配管理员权限。修改本人密码后需要重新登录。

密码登录仍使用单向哈希验证。为满足超级管理员查看密码的需求，新建或重置密码时另外保存加密副本，只有超级管理员可在修改账号界面点击“查看密码”获取明文，退出界面或点击隐藏即清除显示。升级前只有哈希的密码无法还原，显示“原密码不可查看，重置后可查看”。密码查看接口不缓存，操作日志记录查看行为但不记录密码值。

加密密钥位于服务端 `DATA_DIR/credential.key`，默认 `data/credential.key`，不提交 Git。迁移或备份时必须与数据库配套保留并限制访问。丢失密钥会影响查看加密密码，不影响已有密码登录；恢复原密钥或重置密码后才能再次查看。

操作日志从本次升级后开始，包含成功的登录、退出、账号与公共资料维护、记录创建修改核对作废还原、图片上传、识别发起、导出和密码查看。日志保留当时的操作人名称、时间、操作类型及对象，支持分页；不记录密码、API 密钥或模板内容。它不是页面点击录像，不补录升级前的操作，也不记录普通列表读取、失败请求和后台清理。查验记录原有的修改历史仍单独保留。

## 排序与批量作废

查验记录的业务表头可点击排序，再次点击切换升降序；箭头表示当前顺序，空值置后。接收数量按数字自然顺序比较。管理员勾选记录后点击“批量作废”，确认后所选记录一起移入回收站。任一所选记录已被修改或作废时，整批不执行，刷新列表后重新选择。单次最多200条。

## 拖动合并

图片分组手柄拖到目标组中间即合并，拖到边缘或组间空隙调整顺序，拖出列表后松手取消。目标组保留已有字段，来源组补充空白字段，图片和生产日期汇总；有内容需要合并时会先提示，接收总数量需人员核对。不同检验结果不合并。键盘可用上下键排序，按 M 进入合并选择，再用上下键选目标，Enter 确认，Escape 取消。

## 共享物料资料与录入保存

物料维护支持名称、型号、别名，以及规格、供应商或生产商、地址、联系方式、保质期、包装和地址/联系方式来源。旧物料的新增字段为空，不改变已保存查验记录。选择共享物料时带入已维护资料，仍可手动修改；物料中未维护的字段保留当前录入值。日期、接收数量和检验结果不作为共享物料资料沿用。

管理员和超级管理员可在录入的基本信息区域点击“保存为物料信息”，先核对资料，再保存为新的共享物料，不静默覆盖已选物料。此操作不代替本次查验记录的保存。普通用户可选用物料并修改本次记录，但不能写入共享物料库。

本地和云端识别通常只补空白，已有值可从字段建议主动选用。新增记录识别到同种物料并匹配已核对历史后，按下文历史复用规则自动带入台账及检验信息。人工填写或清空的字段保持原样。

物料只绑定一套检验方案时，选择物料后自动带入；未检验时保留选择，开启检验再显示项目。多套方案由人员选择，已有检验项目不自动覆盖。管理员可以在检验项目区将填写的项目另存为公共检验方案，仅保存项目名称和标准规定，不沿用本次检验结果和结论。

## 保质期与报告批号

识别出的物料名称补入基本信息的空白字段，并直接用于 Word 检品名称。报告产品批号默认反斜杠 `\`，可修改或清空；生产日期仍单独显示。

基本信息新增“保质期至”，暂不增加到 Excel 或 Word 模板。保质期的年、月统一规范为“几个月”，例如2年变为24个月、12月变为12个月；录入、共享物料、旧记录显示及导出采用相同规则。纯数字按月理解。包装以天数标注时保留原文并提示人工核对，不按30天折月。

识别到生产日期和期限时，按“生产日期加期限再减一天”补全空白到期日，例如 2026.01.14、12个月得到 2027.01.13。按日历月计算，目标月份没有对应日时取月底，再减一天；天数按实际天数计算；多个生产日期取最早到期日。已识别明确到期日期时保留，并与计算值核对；冲突提示人工处理。生产日期和明确到期日也能反推空白保质期。手工填写或清空的值不会被识别替换，确定的年/月只作等值单位转换。

## 导出预览与报告附件

台账每行“查看”及勾选后的“预览 / 打印”打开实际导出预览，默认 Excel，可切换 Word。预览使用当前账号在浏览器中选定的个人模板，否则使用服务器默认模板，生成可打印 PDF。点击“打印”调用浏览器打印；浏览器无法内嵌 PDF 时可打开 PDF。未检验记录仍可预览和导出 Excel；Word 会提示取消选择未检验记录。待核对记录须确认后预览。

服务器需要 LibreOffice 或本机 Microsoft Word/Excel 来生成 PDF。本地已使用 Office；公司服务器部署时安装 LibreOffice及中文字体。未安装转换工具时，界面显示原因，原有 Excel/Word 下载不依赖 PDF 转换。

新增记录即可在报告附件区选入图片、PDF、Word、Excel或文本报告，每文件最多20 MiB。待上传文件随当前分组保存，保存前可移除，关闭或刷新页面前请先保存。批量记录主体仍一次提交，附件随后按组上传；上传失败会明确提示记录已保存，保留剩余文件，重试不重复创建记录。损坏文件可移除后继续。选择“已核对”时，在对应附件上传成功后再核对。

待上传附件也提供“查看”。图片和 PDF 直接在浏览器预览；Word、Excel 和文本通过临时预览接口读取，Office 文档转换后显示 PDF。预览不会创建查验记录或保存报告附件，关闭预览后仍需保存记录。

已保存记录在“查看与核对”中可直接上传、查看和下载报告。所有登录人员可查看和下载，创建人和管理员可以上传、删除。上传或删除会记录操作并将已核对记录重置为待核对，页面未保存的其他字段仍保留。无检验项目的记录也可保存供应商报告附件。作废后附件只读，恢复时保留；回收站超过30天清理记录时同时删除附件文件。备份时保留整个 `data/report-attachments` 目录。

检验项目每行提供“移除项目”；另存为检验标准方案时，方案名称自动取当前检验依据，可修改。识别范围扩展至明确标注的包装、批号、执行标准、到货数量和随车证件等。净含量不作为接收数量；图片上的感官描述、检验日期等需人员确认，不代替本次检验。字段旁的黄色建议区可逐项选择填入，已有人工内容不会自动覆盖。云端单字段格式异常只提示该字段核对，保留其他有效字段；缺失日期留空，完整JSON外的说明文字不再导致整份结果丢弃。

“抽检项目”可手动维护。选择或更换方案、添加或移除检验项目、直接 OCR 提取及保存记录均不自动拼接此栏；匹配同种物料的已核对历史后可以复用历史内容，仍可修改。

无明确标签的数字日期支持 `20260114`、`2026.01.14` 等格式。汇总同一物料多张图片后，较早日期填生产日期，较晚日期填保质期至；只有一个日期时作为生产日期，再按已有期限推算到期日。明确标注的日期优先，多个明确生产日期保留；排除无效日期、电话、批号及带时间的拍照水印。新结果只自动补空，人工填写或清空的日期不会被覆盖。

台账查找支持物料、供应商、规格、备注或记录编号，可组合核对状态、检验状态、创建人、到货日期及全部台账中的公司筛选。回收站另支持作废日期筛选。筛选可一键清空。

回收站提供“永久删除”，仅管理员和超级管理员可用，确认后删除该记录、修改历史及报告附件，无法还原；相关操作仍保留在操作日志中。共享照片和识别任务不随单条记录删除。超过30天自动清理规则保留。

超级管理员的“所有人员操作日志”支持操作人、操作类型、操作对象和日期范围组合筛选，按筛选结果统计和分页。日期范围按北京时间全天计算，含起止两天；操作人候选保留历史账号名称。

回收站支持勾选记录、“全选筛选结果”“清空选择”“批量还原”和“批量永久删除”，仅管理员及超级管理员可用。操作仅针对当前筛选结果内勾选的记录，单次最多200条，操作前确认数量。还原后均为待核对；永久删除同时删除修改历史和报告附件，无法恢复。若有记录被其他人修改、还原或删除，整批不处理，刷新后重新选择。

操作日志支持按页勾选、全选本页和批量永久删除，仅超级管理员可用；翻页、筛选、刷新后清空选择。删除日志不删除查验台账。日志清理操作本身不再生成新日志，避免始终剩一条及分页位置移动；已有的删除日志也可选中删除。日志按发生时间保留30天，超过30天后在服务启动或后台每小时清理时永久删除，恰好30天仍保留。该规则适用于已有日志，页面顶部黄色提示说明保留期限及无法恢复。查验记录自身的修改历史仍按原记录的保留规则处理。
选择检验标准方案会将当前方案名称重新带入检验依据，随后可手工修改或清空。Word导出的上方基本信息单元格水平、垂直居中；“其他检验项目依据该公司提供的内检报告为准”固定保留，不因内检报告选项为空或为“否”消失。签名图片继续使用当前模板中的图片。

## 2026-10-18 检验选项、英文包装与历史复用

检验结果改为可输入的单选下拉框，默认“符合／不符合”；判定结论默认“合格／不合格”。输入自定义内容并离开输入框后保存为共享历史选项，保存查验记录时也会记住。两类历史分别保存。自定义选项右侧的叉仅删除选项，不改当前或旧记录；再次输入同名内容可恢复。固定选项不能删除，业务字段仍可留空。

本地 OCR 增加英文包装标签解析，包括品名、厂家、规格、电话、包装、MFG、EXP、Shelf Life 等。英文原文保留在识别文字与字段建议中。开启云端辅助后，现有智谱模型同时提供中文翻译，译文只补空白，已填写内容需从字段旁建议手动选用。陌生公司专名可能保留英文，请人员核对译名。未开启云端、密钥不可用或网络失败时，可直接选用本地英文结果继续保存。英文日月顺序有歧义的日期提供候选，不直接猜测。

包装识别到多个供应商、生产商或多处地址时，保留各个候选，在“供应商或生产商”“地址”输入框下方分别列出，由人员点击填入。支持同一图、多图、局部识别及云端补充结果，合并完全重复项，保留已选候选便于重新选择。能识别的单位类型显示在候选文字前，仅作核对参考。选择地址只填写地址文字，不自动填入或更改地址来源；识别补入单个地址同样不自动填写地址来源。多候选时历史复用不会自动覆盖这两个字段，人员已填内容和地址来源保留。已有识别任务需重新识别以生成完整候选。

先识别本次图片的物料名称，再匹配已核对历史，图片相同本身不作为匹配依据。名称匹配支持此前人工核对过的识别名称修正；供应商文字或规格写法不同不再直接阻止匹配。一个识别名称对应不同物料或型号且无法区分时提示未匹配，不自动套用。手工创建且已核对的记录也可以作为来源。

明确匹配后，自动采用该物料最近一次已核对的完整台账快照，包括物料资料、随车证件、感官、抽检项目、备注，以及检验开关、全部检验项目和结果、包装、检验依据、内检报告选项和报告结论，不再要求选择历史方案。界面显示来源公司、记录编号、版本及核对日期。新增记录的历史资料可替换自动识别的稳定字段，但不覆盖人工填写或清空的值，之后仍可修改。未核对及作废记录不参与复用。

到货日期、生产日期、保质期、保质期至、接收数量、批号、检验日期不从历史复制，使用本次信息；没有识别到的值保持空白或原有默认值。到货和检验日期默认为当天。打开已保存记录不会套用新历史改写内容。复用历史不会自动将记录标记为已核对；人员需按本次实际检验核对。云端关闭或失败时，本地识别结果仍可用于匹配。

操作日志的“操作内容”展示操作及具体对象名称、台账记录编号，支持按新日志中的名称搜索。新日志保留操作当时的名称快照；旧日志只按现有资料补充并明确标注，无法确定的显示“旧日志未保存具体对象”。不记录密码、密钥、请求正文或台账备注。
