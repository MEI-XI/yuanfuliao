# 本地运行与模板维护

## 识别进度与人工复核反馈

识别按钮旁显示提交、排队数量、识别中和完成状态。处理期间不能重复点击；同一用户对同组图片重复提交会复用仍在处理的任务。状态查询中断时点击“重试获取状态”，只恢复中断组，不重跑已经完成的组。识别中仍可人工填写和保存。

保存并标记“已核对”后，记录可作为后续识别参考。这是复用人工复核资料，不会自动训练或修改 OCR 模型参数。新照片识别出的物料名称（含型号）、单位名称、规格三项均完整且与历史原识别内容或核对内容匹配时，参考已核对的名称、规格、单位、地址、电话和保质期，自动填入空白字段。已有内容、人工清空或人工选择的来源不覆盖。

参考区显示公司台账、记录编号、版本及核对日期。日期、接收数量、检验结果和结论每次单独填写；当前或历史图片的物料身份有冲突、多条参考记录对同一资料有不同值时，不自动采用有歧义的资料。地址/电话与供应商或生产商来源成对带入。记录修改为待核对、或作废后，不再作为新的自动填入参考。

## 当前电脑

项目位于 `D:\DOME\yuanfuliao`，双击 `启动本地测试.cmd`，保持启动窗口开启，用浏览器访问 `http://127.0.0.1:8000`。启动时自动检查数据库并执行版本迁移。

首次访问建立超级管理员账号；已有系统的 admin 账号在本次升级时成为超级管理员。之后管理员在“管理与公共资料”维护账号、角色、公司台账、物料、检验标准方案和单位资料。没有公开注册入口。系统不预置业务账号或通用密码。

当前电脑使用项目专属 PostgreSQL，监听 `127.0.0.1:55433`，数据目录 `data/postgres-local`。连接信息在本地 `.env` 中；不要将该文件提交代码仓库。关闭网页服务不会删除数据库。停止网页服务按 Ctrl+C；若需要停止项目数据库，可运行 `tmp/pg-runtime/pgsql/bin/pg_ctl.exe -D data/postgres-local stop`。

同事在其他电脑上测试时，只需浏览器打开局域网网站，不需要安装依赖。将来更换服务器时，服务器按 README 安装依赖、提供 PostgreSQL，并从 `.env.example` 建立 `.env`。本机临时下载的便携数据库程序在 `tmp/pg-runtime`，不在 Git 仓库内，不是通用安装器。

## 手机和电脑

本地阶段：手机与电脑连接同一个局域网，在手机浏览器输入 `http://电脑局域网IP:8000`。电脑可用 `ipconfig` 查看当前网络 IPv4 地址。Windows 防火墙如拦截，允许 Python 服务的专用网络访问。当前阶段不配置公网映射。

手机支持相册选图和拍照上传，电脑支持选择文件和拖放。批量模式默认一图一组。图片左侧的窄栏按“记录 → 图片缩略图”分层纵向显示，点击子图片直接预览。拖动记录手柄调整分组顺序，电脑和手机均支持，也可聚焦手柄使用上下方向键；顺序改变不会移动图片所属记录或丢失当前填写内容。识别到相同物料会给出合并提示，人员决定是否合并、移动或拆分。已保存记录通过修改或作废重建处理。

全部有效记录均可查看和按规则导出；普通用户只修改、核对自己的记录，管理员可修改全部记录并作废。默认选择已核对记录导出，待核对需确认，作废不能导出。

## 识别与核对

本地 RapidOCR 先运行，识别后台排队，人员可以继续手填和保存。默认启用云端辅助，但没有密钥或服务失败时仍能使用本地结果。管理员可配置智谱密钥，型号固定为 `glm-4.1v-thinking-flash`，不切换收费型号。云端服务的可用性与免费政策由提供方决定，无法保证永久免费。

管理员在“管理与公共资料 → 云端与模板”粘贴智谱官方 API Keys 页面的完整密钥，先点“保存密钥”，再点“测试连接”。测试使用服务器保存的密钥，验证认证及模型文字请求；包装识别效果仍需上传照片核对。HTTP 401 表示认证失败，需重新复制完整有效密钥；403 检查账号权限，429 检查限额并稍后重试。云端错误也显示在识别按钮旁，本地结果保留。密钥不会回显或提交 Git。

识别建议不会覆盖人工修改。保存后仍能打开原图和识别原文。生产日期显示与导出为 `2026.01.14`；Word 原有“生产日期批号”使用该日期，独立“批号”保持空白。接收数量、检验结果和结论每次由人员填写，可留空。

图片不清楚、地址电话很小、产品名称被折痕遮挡时，查看原始文字、补拍特写或手动修正。不要把历史台账中的日期、收货数量或检验结果作为本次识别事实。

## 回收站

作废记录从公司台账和“全部记录”中移除，单独放在顶部“回收站”。所有已登录人员可查看并按公司或物料搜索，管理员可还原。还原保留原字段、检验内容、图片与历史，回到待核对状态，需重新核对后使用。

超过作废时间 30 天的记录及其修改历史自动永久删除，不能再还原。服务启动时和运行中每小时清理一次，进入回收站时也清理到期记录；停机期间不运行，重新启动后补清理。旧作废记录以原作废操作更新时间起算。共享的照片和识别任务不会因某条记录到期而删除，避免影响其他记录。

## 批量保存

多种物料批量录入后，勾选需要保存的分组，可用底部“全选分组”“全部清空”调整选择。底部显示“保存所选 N 条记录”，与“同时标记为已核对”勾选项放在同一栏，替换单条保存按钮。核对选项默认不勾选；所选组按当前分组顺序保存，未选组保留在录入界面。检验/未检验状态仍分别取各组设置。没有勾选时可按原方式保存当前记录。

任一组校验失败，整批均不保存；草稿保留供修正。识别正在处理时等待完成后再批量保存，仍可按原方式逐条保存。若网络中断、尚未确认提交结果，临时锁定本批草稿，点击“重试批量保存”继续确认同一批次，避免重复创建。

## 检验方案与导出选择

新增记录默认“未检验”，检验项目和报告信息收起并锁定。选择“检验”后展开；切回“未检验”保留已填内容，再次开启可继续填写。“检验”表示启用本次检验，不等同于已核对或检验合格。更新前的已有记录保留原报告能力，显示为“检验”，人员可自行切换。

新记录的检验日期默认当天，使用上海时区，仅年月日，可修改或清空。重新打开已有记录不改写原日期。检验项目只填写项目、标准规定、检验结果和判定结论，不再提供单位字段；历史独立单位不再附加到报告项目名称。

台账另列“检验状态”。Excel 可导出未检验记录；Word 只允许检验记录。所选记录中包含未检验记录时，提示取消勾选后再导出，不会静默跳过。

检验标准方案的所属物料可留空。所属物料仅作提示，所有物料都能选择任意方案；已开启检验时，选择仅绑定一套方案的物料，空白项目可自动带入。人员也可以从“已维护检验项目”中选择单项加入，其他已填结果保留。更换物料保留已有项目；明确选择“不选择方案”后，保存不会再自动改成另一套方案。已保存记录保留当时的项目快照。选择整套检验方案时，“检验依据”默认带入方案名称，可手动修改或清空；已经手改的依据不会被后续方案选择覆盖。

台账中先勾选需要的记录，可“全选当前记录”或“清空选择”。仅导出当前筛选中选中的记录。Excel 按公司分表，标题使用各表第一条导出记录的到货年份；首条日期为空则不带年份。多条 Word 每条单独生成一份并打包 ZIP，文件名为“品名_检验日期.docx”，未填检验日期时使用录入日期（上海时间）。重名依次加 `(1)`、`(2)`，非法文件名字符替换为下划线，过长品名只截短文件名，报告正文保持原文。

## 个人模板与签名

所有用户从顶部“我的模板”选择自己电脑上、项目目录之外的专用文件夹，可以更换目录，也可快捷打开以该目录为起点的系统目录选择窗口。采用纯网页方案，不需要安装小助手。

首次选择时仅补齐缺失的两个默认模板，不覆盖已有文件：

- `查验台账.xlsx`：保留 A1 标题、表头行以及原来的 13 列。
- `检验报告.docx`：保留字段占位符和检验项目循环表格，原有签名图片保留。

报告信息不再填写检验员和批准姓名。点击“修改模板文件”进入“我的模板”，设置后可返回录入界面继续未保存内容。用 Word/WPS 修改自己文件夹中的签名图片并保存；报告保留模板图片，不带入旧记录手填的签名姓名。实时目录模式每次导出重新读取文件，导入副本模式读取最近一次导入的内容；修改过的模板临时发送给服务器用于本次导出，不保存、不替换服务器默认模板。未修改或对应文件缺失时使用服务器最新默认模板。单个个人模板不超过 10MB。选择“使用服务器默认模板”只切换使用方式，不删除本地文件。

目录设置和初始文件校验值保存在当前浏览器，按登录账号区分。清除网站数据或换浏览器后需重新选择；浏览器拒绝读取权限时，导出会提示重新授权，不会悄悄忽略个人模板。网页只能显示文件夹名称，不能读取完整磁盘路径。

实时读写目录需要桌面 Chrome/Edge 和 HTTPS 或 localhost。普通局域网 HTTP 地址提供模板文件夹导入：选择文件夹后，将本次读取的模板副本保存在当前浏览器中，按账号区分；修改本地模板后须重新选择文件夹导入。页面明确区分实时目录与导入副本，不会把导入副本写回磁盘或服务器。可下载默认模板后，用 Word/WPS 修改并保存到自己的文件夹再导入。首次授权和日后浏览器要求重新授权时，需要人员在系统窗口确认。[浏览器文件访问说明](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access)

服务器仍保留默认模板供未设置个人模板的用户使用，位置由 `TEMPLATE_DIR` 指定，默认 `templates`。这些默认文件由服务器维护人员管理，不作为用户个人模板目录。不要删除 `{{ ... }}` 字段和 `{%tr ... %}` 循环标记。实际模板和签名图片不上传 GitHub。

## 管理资料新增与修改

保留原有大分类，每个小模块首先显示自己的列表。例如“物料与检验标准”下分别显示共享物料列表和检验标准方案列表，每个列表有自己的新增入口。单位、账号和台账采用同样方式。

点击“新增物料”等按钮，进入该小模块的空白新增界面，按钮显示“创建物料”等。点击某条记录的“修改”，进入标题含原名称的修改界面，按钮显示“保存修改”。完成后自动返回列表；点击“返回列表”或“取消返回”不保存，下一次新增仍为空白，不沿用编辑对象。云端密钥也区分首次配置与更新界面，保存后回到列表测试连接。

## 管理资料删除

管理员可删除共享物料、检验标准方案、单位资料、人员账号和公司台账，删除前按名称确认。删除物料会解除方案及记录的物料关联，记录中的字段、项目、标准快照和历史仍保留；删除方案和单位资料同样不清空已保存记录。

当前登录账号不能删除；已有记录、核对历史、照片或识别任务的账号不能删除，可改为停用。已有记录、照片或识别任务的台账不能删除，仅允许删除空台账。云端设置可通过“清除密钥”移除密钥。

## 公司服务器部署准备

提供 `Dockerfile`、`compose.yaml` 和 Nginx 配置示例。当前环境没有 Docker，容器构建、公司服务器网络与 HTTPS 尚未实机验收，不能视为已部署。

服务器准备 Python/Node 构建环境或 Docker Compose、域名与 TLS 证书。Compose 使用单个应用进程和 PostgreSQL；在服务器 `.env` 设置 `POSTGRES_PASSWORD`（建议使用随机字母数字密码以避免连接串转义问题）。将本地模板单独复制到服务器 `templates`。服务默认只绑定回环地址，经 Nginx 提供 HTTPS；HTTPS 上设置 `COOKIE_SECURE=true`。

本版识别任务在数据库记录状态、单进程后台执行；重启中的任务会标记失败，用户可重试。不要直接增加 Uvicorn worker 数量；需要扩容时先改为独立队列执行器。

迁移包含数据库、`data` 中的上传图片、`templates` 以及服务端配置。数据库用 `pg_dump -Fc` 备份，以 `pg_restore` 恢复到新的数据库并验证；不要复制正在运行的 PostgreSQL 数据目录作为备份。模型可重新下载，已下载后断网也可运行本地识别。正式上线前进行恢复演练、HTTPS、手机外网访问及账号权限验收。

## 超级管理员与操作日志

超级管理员可修改账号名称、重置所有账号密码、分配普通管理员权限，并在“操作日志”中查看所有人员的新操作。超级管理员账号不可删除、停用或降级；普通管理员不能修改超级管理员或分配管理员权限。修改本人密码后需要重新登录。

密码登录仍使用单向哈希验证。为满足超级管理员查看密码的需求，新建或重置密码时另外保存加密副本，只有超级管理员可在修改账号界面点击“查看密码”获取明文，退出界面或点击隐藏即清除显示。升级前只有哈希的密码无法还原，显示“原密码不可查看，重置后可查看”。密码查看接口不缓存，操作日志记录查看行为但不记录密码值。

加密密钥位于服务端 `DATA_DIR/credential.key`，默认 `data/credential.key`，不提交 Git。迁移或备份时必须与数据库配套保留并限制访问。丢失密钥会影响查看加密密码，不影响已有密码登录；恢复原密钥或重置密码后才能再次查看。

操作日志从本次升级后开始，包含成功的登录、退出、账号与公共资料维护、记录创建修改核对作废还原、图片上传、识别发起、导出和密码查看。日志保留当时的操作人名称、时间、操作类型及对象，支持分页；不记录密码、API 密钥或模板内容。它不是页面点击录像，不补录升级前的操作，也不记录普通列表读取、失败请求和后台清理。查验记录原有的修改历史仍单独保留。

## 排序与批量作废

查验记录的业务表头可点击排序，再次点击切换升降序；箭头表示当前顺序，空值置后。接收数量按数字自然顺序比较。管理员勾选记录后点击“批量作废”，确认后所选记录一起移入回收站。任一所选记录已被修改或作废时，整批不执行，刷新列表后重新选择。单次最多200条。

## 拖动合并

图片分组手柄拖到目标组中间即合并，拖到边缘或组间空隙调整顺序，拖出列表后松手取消。目标组保留已有字段，来源组补充空白字段，图片和生产日期汇总；有内容需要合并时会先提示，接收总数量需人员核对。不同检验结果不合并。键盘可用上下键排序，按 M 进入合并选择，再用上下键选目标，Enter 确认，Escape 取消。

局域网部署步骤见 [局域网测试说明](局域网测试说明.md)。

## 共享物料资料与录入保存

物料维护支持名称、型号、别名，以及规格、供应商或生产商、地址、联系方式、保质期和地址/联系方式来源。旧物料的新增字段为空，不改变已保存查验记录。选择共享物料时带入已维护资料，仍可手动修改；物料中未维护的字段保留当前录入值。日期、接收数量和检验结果不作为共享物料资料沿用。

管理员和超级管理员可在录入的基本信息区域点击“保存为物料信息”，先核对资料，再保存为新的共享物料，不静默覆盖已选物料。此操作不代替本次查验记录的保存。普通用户可选用物料并修改本次记录，但不能写入共享物料库。

已有字段无论来自手工、共享物料、已保存记录还是之前的识别，重新识别时均保留；仅空白字段自动补充。人工清空的字段仍保持为空，避免立即又被自动填回。已有值需在本地字段建议、云端建议或历史参考中主动选择填入。
