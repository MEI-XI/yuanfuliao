# 导出模板

此文件夹放置 `查验台账.xlsx` 和 `检验报告.docx`，系统每次导出重新读取。

Excel 保留标题行和原来的 13 列表头。Word 保留原模板版式和签名图片；支持带占位符模板，也可直接使用提供的七行四列检验报告单。使用 Word/WPS 可以直接更换签名图片，保存后下次导出生效。更换签名时不要删除附近的字段占位符。

原始办公文件不随代码上传 GitHub。当前电脑已放入提供的模板副本；其他电脑需要复制此文件夹中的办公文件。修改模板前自行留一份备份，避免 Word 未保存或占用文件时导出。

2026-10-15 默认 Word 已替换为指定的“模板文件夹/检验报告.doc”的等版式 DOCX 转换件。个人模板从网页分别选择任意名称的文件，旧格式临时转换，不能替换此目录默认文件。
